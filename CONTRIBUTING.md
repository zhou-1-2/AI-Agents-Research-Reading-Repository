# Contributing

[Home](README.md) · [Paper Index](PAPER_INDEX.md) · [Open Problems](OPEN_PROBLEMS.md)

## Adding a paper

1. Verify bibliographic metadata using a primary source.
2. Check for an existing entry and reuse its ID if present.
3. Register the paper in the central index.
4. Copy the [reading template](templates/paper-reading-template.md) into an appropriate topic folder with a descriptive filename.
5. Link the note from the topic index and central index.

## Research questions

Use the [question template](templates/research-question-template.md). Distinguish an exploratory question from a verified literature gap. Link evidence for status changes.

## Quality standards

Write in clear English. Cite specific sections or pages when discussing claims. Distinguish reported, interpreted, proposed, and reproduced findings. Include limitations and contradictory evidence. Do not invent citations, results, or completed reading activity.

Use relative Markdown links for repository content. Check targets and heading anchors before submitting. Keep one canonical note per paper and cross-link across topics.

## Changes

Keep changes focused. Explain the addition and its evidence in the commit or pull request. Do not upload copyrighted paper PDFs without permission, private data, credentials, or large generated artifacts.
